개인정보처리방침 / Privacy Policy

시행일 / Effective date: 2026-10-16

1. 이용 범위 / Scope

10조 보고 메일은 운영자 본인만 사용하는 내부 도구입니다. Google 계정의 Gmail 메일 보내기 권한(https://www.googleapis.com/auth/gmail.send)만 사용하며, 운영자 본인 계정으로 운영자 본인 주소에 보고 메일을 보내는 데에만 씁니다.

This app is used only by its owner. It uses only the Gmail send permission, solely to send report e-mails from the owner's account to the owner's own addresses.

2. 수집·저장하는 정보 / Data collected

메일함을 읽지 않으며, 어떠한 개인정보도 수집·판매·공유하지 않습니다. 로그인 인증 정보(OAuth 토큰)는 운영자 PC에만 저장됩니다.

The app does not read mailboxes and does not collect, sell or share any personal data. OAuth tokens are stored only on the owner's computer.

3. Google 사용자 데이터 / Google user data

Google API로 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. 권한 철회 / Revoking access

Google 계정 설정 → 보안 → 서드 파티 앱 액세스에서 언제든 권한을 철회할 수 있습니다. / Access can be revoked at any time in Google Account → Security → Third-party access.
